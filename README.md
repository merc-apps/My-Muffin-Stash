My Muffin Stash

A personal budget tracker that runs entirely in your browser - no account, no server, no data leaving your device.

Features
Log expenses, income, savings, and investments with custom categories

Multiple budgets — keep separate trackers (e.g. personal, family) side by side

Templates — save a category setup and reuse it when starting a new budget

Dedicated summary boxes for Essential Expenses, Debt, Date Nights, Fun Money, and Investments

A savings goal progress ring, plus pie charts for spending, savings, and investments by category

Light and dark mode (follows your system setting, or toggle manually)

Privacy
All data is stored using your browser's local storage — nothing is sent to a server. This means:

Your budgets and entries stay on your device and in this specific browser

Data won't sync across devices or browsers

Clearing your browser data will erase your budgets

Everyone who opens this page gets their own private, separate set of data

Running it locally
This is a single self-contained HTML file. To run it without GitHub Pages:

Download index.html (or ledger.html) from this repo
Open it directly in any modern browser

No build step, no dependencies, no installation required.

Tech
Plain HTML, CSS, and vanilla JavaScript — no frameworks, no external libraries beyond Google Fonts.
